# アメダス都道府県統計ビューア

気象庁（JMA）のアメダス公開データを使って、選択した都道府県の降水量・気温・湿度・風の統計量を計算し、地図上にヒートマップ・等高線として可視化するブラウザアプリです。`index.html` 1ファイルで完結します。

## ソフト概要

- 都道府県を選択すると、その都道府県内のアメダス観測点データを気象庁の公開APIから取得します。
- 降水量（累計・平均）、気温（平均）、湿度（平均）、風（合成ベクトル平均・RMS）を JavaScript 内で計算します。
- Canvas 上に観測点・都道府県境界（GeoJSON）・ヒートマップ・等高線（IDW補間 + マーチングスクエア法、自前実装）を重畳描画します。
- 拡大縮小・ドラッグ移動・ホバーでの観測点値表示に対応します。
- 統計区間は **過去1時間**（10分間隔×6点）と **過去24時間**（1時間間隔×24点）から選択でき、どちらも気象庁の公開APIから完全に実測データを取得できます。
- 東京都の小笠原諸島のように本土から大きく離れた離島は、自動的に「本土」「離島1」…といった別地域として検出され、UIから切り替えて表示できます（地図の縮尺が離島に引っ張られて本土が判読不能になるのを防止）。
- ヒートマップは都道府県境界のすぐ内側で途切れず、近傍の観測点（隣接都道府県を含む）を使って境界の外側までなめらかに描画されます。

詳細な設計は [`設計書.md`](./設計書.md)、元の要件は [`要件.txt`](./要件.txt) を参照してください。

## 技術的特徴

- **単一HTML完結**: HTML/CSS/JavaScript をすべて `index.html` 1ファイルに集約。外部JSライブラリは不使用（`fetch` によるデータ取得のみ）。
- **純粋関数とDOM処理の分離**: 統計計算・幾何演算・補間ロジックを `window.AmedasApp` として DOM/`fetch` に依存しない形で実装し、Node.js からユニットテスト可能にしています。
- **自前実装の空間補間**: IDW（逆距離加重法）によるグリッド補間と、簡易マーチングスクエア法による等高線生成をライブラリなしで実装。
- **`requestAnimationFrame` による描画ループ**: パン・ズーム・レイヤー切替を滑らかに反映します。

## 依存ライブラリとインストール手順

アプリ本体（`index.html`）に依存ライブラリはありません。ブラウザで開くだけで動作します。

テストを実行する場合のみ Node.js が必要です（追加パッケージのインストールは不要、Node.js 標準の `node:test` を使用）。

```bash
# 動作確認済みバージョン例: Node.js v24
node --version
```

## 起動方法

リポジトリを取得し、`index.html` をブラウザで開くだけです。

```bash
git clone https://github.com/himayah/amedas-pref-viewer.git
cd amedas-pref-viewer
# ブラウザで index.html を開く（例: WSL/Linuxの場合）
xdg-open index.html   # または直接ブラウザにドラッグ&ドロップ
```

インターネット接続が必須です（気象庁の観測データと都道府県境界GeoJSONを実行時に取得するため）。

## 使用方法

1. 左側パネルで **都道府県** を選択します。
2. **統計区間**（過去1時間／過去24時間）を選択します。
3. **「取得・描画」** ボタンを押すと、観測点データの取得・統計計算・地図描画が実行されます。進捗はログパネルに表示されます。
4. 取得後、都道府県に離島など複数の地域が検出された場合は **「地域」** プルダウンが有効になります。切り替えるとネットワーク再取得なしに、その地域の統計・地図へ即座に切り替わります。
5. **描画項目**（降水量・気温・湿度・風速・風向）を切り替えると、地図表示とツールチップの内容が更新されます。
6. **レイヤー表示チェックボックス**（ヒートマップ／等高線／観測点／都道府県境界）で表示要素を切り替えられます。
7. 地図上でマウスホイールによる拡大縮小、ドラッグによる移動ができます。「表示リセット」ボタンで初期表示に戻せます。
8. 観測点にマウスを重ねると、その地点の値がツールチップで表示されます。

## 終了方法

ブラウザのタブを閉じるだけで終了します。バックグラウンドプロセスやサーバーは起動しません。

## 使用上の注意点

- **地域（本土／離島）ラベルについて**: 「本土」「離島1」「離島2」…という表示は観測点数に基づく機械的な命名であり、実際の地名（伊豆大島、宮古島 等）を示すものではありません。地図の位置と統計値で実際にどの地域かを確認してください（詳細は [`設計書.md`](./設計書.md) §5.2, §9 #7）。
- **ヒートマップの境界外描画について**: 境界の外側約0.15度（15〜17km程度）まで近傍観測点を使って補間描画しますが、これは簡易的な緯度経度距離による近似であり、実際の距離（球面上の距離）とは高緯度ほどややずれます（§5.3）。
- 都道府県境界GeoJSON（[`dataofjapan/land`](https://github.com/dataofjapan/land), MIT License）は初回のみ約13MBの取得が発生します（ブラウザキャッシュにより2回目以降は高速化されます）。
- 風の統計（合成ベクトル平均・RMS）は「過去1時間」は10分間隔6サンプル、「過去24時間」は1時間間隔24サンプルの近似値であり、気象庁の公式統計値とは一致しません。
- 本アプリは気象庁・国土数値情報等の公開データを利用していますが、気象庁および `dataofjapan/land` プロジェクトの公式サービスではありません。防災・医療等の重要判断には気象庁の公式発表を参照してください。

## テストの実行方法

```bash
npm test
```

`window.AmedasApp` の純粋関数群（統計計算・幾何演算・補間・等高線生成・地域クラスタリングなど）を Node.js の `node:test` で検証します（計31ケース）。
