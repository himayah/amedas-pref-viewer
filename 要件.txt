あなたはブラウザアプリを生成するエンジニアとして振る舞ってください。
以下の仕様を満たす Web アプリを、HTML/CSS/JavaScript の単一ページ構成で生成してください。

# 目的
指定した都道府県について、過去1年分のアメダスデータを取得し、
降水量・気温・湿度・風向風速の統計量を計算し、
地図上に等高線やヒートマップとして描画できるブラウザアプリを作成する。

# データ仕様
- データソースは気象庁のアメダス公開APIまたはCSV（過去データ）を使用すること。
- 過去24時間 / 過去1か月 / 過去1年 の3区間について統計量を計算する。
- 対象都道府県はユーザーが UI で選択できるようにする。

# 計算仕様
- 降水量：累計値・平均値
- 気温：平均値
- 湿度：平均値
- 風：以下の2種類を計算する
  - 合成ベクトル（u,v 成分を合成して平均風向・平均風速を求める）
  - 二乗平均平方根（RMS）
- 統計計算は JavaScript 内で行うこと。

# 地図描画仕様
- 地図は SVG または Canvas を使用する（どちらでも可）。
- 都道府県境界は GeoJSON を使用する。
- アメダス観測点の位置をプロットし、選択した項目を等高線またはヒートマップで描画する。
- 等高線生成には簡易的な補間（IDW など）を自前実装してよい。
- 描画は requestAnimationFrame を使いスムーズに更新する。

# UI仕様
- 都道府県選択ドロップダウン
- 統計区間（24h / 1m / 1y）選択
- 描画項目（降水量・気温・湿度・風速・風向など）選択
- 地図上に等高線・ヒートマップ・観測点を表示するチェックボックス

# 実装仕様
- 外部ライブラリは使用しない（GeoJSON の読み込みは fetch のみ可）。
- データ取得・統計計算・描画処理をすべて単一ファイル内で完結させる。
- index.html として保存可能な単一ファイルのコードを返す。
- コードブロック内に HTML/CSS/JS をすべて含める。
- 説明は最小限とし、コードを最優先で提示する。
